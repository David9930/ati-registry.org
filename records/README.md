# Records

One JSON file per registered work, named `ATI-YYYY-NNNNNN.json`, validated against
[`schema/record.schema.json`](../schema/record.schema.json). Do not edit these by hand except as a
maintainer handling a dispute (see the maintainer guide in the main README). Git history is the audit trail.

These records are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
